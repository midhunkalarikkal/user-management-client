# User Management

A full-stack user management application built with **React, TypeScript, Node.js, and Express**. It provides a clean, responsive dashboard for managing user records, with authentication, search, filtering, sorting, and pagination.

The application uses **DummyJSON** as a mock data provider, with an Express backend handling API requests and authentication.

## Features

- User authentication
- View, create, update, and delete users
- Search and filter users by different fields
- Sorting and server-side pagination
- Detailed user profiles
- Form validation and error handling using zod
- Responsive dashboard with collapsible sidebar
- API caching and synchronization

## API Integration

The application integrates with [DummyJSON](https://dummyjson.com/) for sample user data.

The Express backend acts as an authenticated API layer for user management operations.

**Note:** DummyJSON simulates create, update, and delete operations. These changes are not permanently stored by the data provider.
